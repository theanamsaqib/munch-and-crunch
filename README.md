Licensors like **Muse Asia, Muse India, Ani-One and GUNDAM** upload full anime episodes to their own YouTube channels for free. The problem: they're scattered across channels and playlists, with no proper search or filters.

**munch & crunch** collects those official playlists, matches each show on [AniList](https://anilist.co) for genres, year and synopsis, and turns them into one catalogue you can search, filter and watch.

> 🎬 **No video is hosted here.** Every episode plays in YouTube's embedded player, from the rights holder's own channel. Only official licensor channels are listed — no re-uploads, fan channels or pirate sources.

## ✨ Features

| | |
|---|---|
| 🔍 **Smart search** | Debounced, case- and accent-insensitive, and matches romaji titles too — `shingeki` finds *Attack on Titan*. Ranked: exact → title prefix → word prefix → substring, ties broken by popularity. |
| 🎛️ **Filters & sorting** | Genre, series vs. movie, and language (English sub, English dub, Hindi, Tamil, Telugu dubs). Sort by relevance, popularity, newest or A–Z. |
| 🔗 **Shareable URLs** | Query and filters live in the address bar, so links, refresh and Back/Forward all restore the same view. |
| 📚 **Seasons & versions** | One show can have several versions — e.g. Muse Asia's English sub alongside Muse India's Hindi dub. Switching keeps your episode number. |
| ▶️ **Watch page** | Previous/next, episode list, and a fallback YouTube link when a video is region-locked. |
| 🔒 **Privacy first** | Playback via `youtube-nocookie.com`. No analytics, no accounts, no cookies of our own ([/privacy](https://munch-and-crunch.vercel.app/privacy)). |
| ♿ **Accessible** | Fully keyboard-navigable, announces result counts to screen readers, respects `prefers-reduced-motion`. |

## ⚙️ How it works

```
 YouTube Data API ──┐                                  ┌─► public/data/catalog.json      (search index)
 (official channels)│     scripts/sync  (npm run sync) │
                    ├─► find episode playlists ────────┤
 AniList API ───────┘     match shows, merge versions  └─► public/data/shows/<id>.json   (episodes)
                                                                       │
                                                                       ▼
                                                React app ─► loads the index once,
                                                             then one file per opened show
```

**1. Collect** — The sync script reads every playlist on the channels in `channels.json` and keeps only full episodes (12–40 min) or feature-length movies. It skips:

- trailers, clips and "Moments" compilations
- multi-show collections, radio shows and events
- copies aimed at other audiences (e.g. Chinese- or Korean-subtitled)
- members-only, private or non-embeddable videos, and episodes blocked in the target region

**2. Match** — Each playlist is looked up on AniList for genres, year, popularity and description. Messy season markers like `(S3)`, `Season2` or `(Season 3): Subtitle` are normalised first.

**3. Merge** — Playlists of the same show become *versions* of it. A season already contained in a full-series playlist is merged in; separate seasons stay separate.

**4. Serve** — The app is a static SPA: it loads the small search index up front and fetches a show's episodes only when you open it.

## 🚀 Getting started

Requires **Node.js 20+**.

```bash
git clone https://github.com/theanamsaqib/munch-and-crunch.git
cd munch-and-crunch
npm install
npm run dev        # → http://localhost:5173
```

The repo ships with a generated catalogue, so it works immediately — **no API key needed**.

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm test` | Run all tests once |
| `npm run test:watch` | Run tests in watch mode |
| `npm run sync` | Rebuild the catalogue (needs an API key) |

## 🔄 Refreshing the catalogue

### 1. Get a free YouTube Data API key (no billing needed)

1. Open the [Google Cloud Console](https://console.cloud.google.com/) and create a project.
2. **APIs & Services → Library** → enable **YouTube Data API v3**.
3. **APIs & Services → Credentials → Create credentials → API key**, and restrict it to YouTube Data API v3.

### 2. Add it locally

```bash
cp .env.example .env.local       # PowerShell: Copy-Item .env.example .env.local
```

Paste your key after `YOUTUBE_API_KEY=` in `.env.local`.

> ⚠️ `.env.local` is git-ignored. Never commit the key or put it in front-end code — the site itself doesn't need it.

### 3. Run the sync

```bash
npm run sync -- --region=IN                 # drop episodes blocked in this country (ISO code)
npm run sync -- --only=muse-india,gundam    # sync only some channels (keys from channels.json)
npm run sync -- --verbose                   # log every playlist as it's checked
npm run sync -- --partial                   # write what was collected even if quota runs out
npm run sync -- --fresh                     # ignore cached YouTube responses
```

### Quota & safety

- **Quota** — The free tier is 10,000 units/day. YouTube and AniList responses are cached in `scripts/sync/.cache/` for 3 days, so a run that hits the limit resumes cheaply the next day.
- **Write guard** — The sync refuses to replace the catalogue with an empty one, or one less than half the current size, unless you pass `--force`.
- **Overrides** — Pin hand-written titles or synopses per show in `scripts/sync/overrides.json`.

## ☁️ Deployment

Configured for Vercel via `vercel.json`:

- **Routing** — refreshes on any route (e.g. `/watch/…`) are served by the app.
- **Security headers** — a Content Security Policy that only allows YouTube's player and thumbnail servers, plus `Referrer-Policy: strict-origin-when-cross-origin` (required by YouTube embeds).
- **Caching** — built assets cached long-term; catalogue data revalidated hourly.

To deploy your own copy, import the repo at [vercel.com/new](https://vercel.com/new) and keep the detected settings. **No environment variables needed.**

### Weekly refresh

`.github/workflows/sync-catalogue.yml` runs every **Monday at 07:30 UTC**: it syncs, runs the tests, and commits the new data if anything changed — Vercel then redeploys. This keeps the data fresh (as YouTube's API policies require) and drops videos channels have removed.

**Setup:** add your key as a repository secret named `YOUTUBE_API_KEY` (**Settings → Secrets and variables → Actions**), then trigger the first run from the **Actions** tab.

```
src/
├── api/          catalogue API (remote JSON for the app, in-memory for tests) + React context
├── components/   cards, search bar, filters, episode list, version picker, status messages

```

## ➕ Adding a channel

Add an entry with the channel's `UC…` ID to `scripts/sync/channels.json`, then run the sync.

> Only add channels run by the **rights holder or an official licensor**. Re-uploads, fan channels and pirate sources don't belong here.

## ⚠️ Limitations

- **Region** — The published catalogue is filtered for India (`--region=IN`). Visitors elsewhere may find some episodes unavailable.
- **Changing availability** — Channels add/remove uploads and some shows are "limited time". The weekly sync catches up, but an episode can vanish in between.
- **Unmatched shows** — A few shows have no AniList match. They still play, just without genres.
