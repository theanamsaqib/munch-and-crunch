# munch & crunch

Search, browse and watch anime that licensors publish **free and officially** on YouTube.

munch & crunch collects the full-episode playlists that rights holders such as Muse Asia,
Muse India, Ani-One and GUNDAM post on their own YouTube channels. It matches each show on
[AniList](https://anilist.co) and presents them as one searchable catalogue, with filters,
seasons, language versions and an episode player.

Every episode plays in YouTube's own embedded player, from the channel that uploaded it.
**This site hosts no video**, and it only lists channels run by the rights holders.

## Features

- **Search**: debounced, case- and accent-insensitive, and also matches Japanese (romaji)
  titles, so "shingeki" finds *Attack on Titan*. Ranking is exact match → title prefix →
  word prefix → substring, with ties broken by popularity.
- **Filters** for genre, series or movie, and language (English subtitles, English dub, Hindi,
  Tamil and Telugu dubs), plus sorting by relevance, popularity, newest or A–Z.
- **Shareable URLs**: the query and filters live in the address bar, so links, refresh and
  Back/Forward all restore the same view.
- **Seasons and versions**: one show can have several, such as Muse Asia's English subtitles
  alongside Muse India's Hindi dub. Switching keeps your episode number.
- **Watch page** with previous/next, an episode list, and a fallback link to YouTube when a
  video is region-locked.
- **Privacy-respecting playback** through `youtube-nocookie.com`. The site has no analytics
  or accounts and sets no cookies of its own (see `/privacy`).
- **Accessible**: works by keyboard alone, announces result counts to screen readers, and
  respects `prefers-reduced-motion`.

## How it works

```
 YouTube Data API ──┐                                  ┌─► public/data/catalog.json   (search index)
 (official channels)│   scripts/sync   (npm run sync)  │
                    ├─► find episode playlists ────────┤
 AniList API ───────┘   match shows, merge versions    └─► public/data/shows/<id>.json (episodes)
                                                                     │
                                                                     ▼
                                              React app (Vite) ─► fetches the index once,
                                                                  then one file per opened show
```

1. **Sync** (`scripts/sync/`) reads every playlist on the channels in `channels.json`. It keeps
   playlists of full episodes: 12–40 minute episodes, or feature-length movies. It skips:
   - trailers, clips and "Moments" compilations;
   - multi-show collections, radio shows and events;
   - copies aimed at other audiences, such as Chinese- or Korean-subtitled ones;
   - members-only, private or non-embeddable videos, and episodes blocked in the target region.
2. Each kept playlist is **matched on AniList** to get genres, year, popularity and a
   description. Season markers written many ways, such as `(S3)`, `Season2` or
   `(Season 3): Subtitle`, are normalised before matching.
3. Playlists for the same show become **versions** of it. A season that's contained in a
   full-series playlist is merged into it, while separate seasons stay listed separately.
4. The **app** is a static single-page site. It loads the small search index up front and
   fetches each show's episode list only when that show is opened.

## Getting started

Requires Node.js 20 or newer.

```bash
git clone https://github.com/theanamsaqib/munch-and-crunch.git
cd munch-and-crunch
npm install
npm run dev        # http://localhost:5173
```

The repository already contains a generated catalogue, so the site works straight away
without an API key.

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm test` | Run all tests once |
| `npm run test:watch` | Run tests in watch mode |
| `npm run sync` | Rebuild the catalogue (needs an API key, see below) |

## Refreshing the catalogue

### 1. Get a free YouTube Data API key

No billing is needed.

1. Open the [Google Cloud Console](https://console.cloud.google.com/) and create a project.
2. Go to **APIs & Services → Library**, and enable **YouTube Data API v3**.
3. Go to **APIs & Services → Credentials → Create credentials → API key**. Restrict the
   key to the YouTube Data API v3.

### 2. Add it locally

```bash
cp .env.example .env.local     # PowerShell: Copy-Item .env.example .env.local
```

Paste the key after `YOUTUBE_API_KEY=` in `.env.local`. That file is git-ignored. Never commit
it, and never put the key in front-end code; the site itself doesn't need it.

### 3. Run the sync

```bash
npm run sync -- --region=IN                 # drop episodes blocked in this country (ISO code)
npm run sync -- --only=muse-india,gundam    # only some channels (keys in channels.json)
npm run sync -- --verbose                   # print each playlist as it is checked
npm run sync -- --partial                   # write what was collected even if quota ran out
npm run sync -- --fresh                     # ignore cached YouTube responses
```

**Quota and safety:**
- **Quota:** the free YouTube quota is 10,000 units a day. YouTube and AniList responses are
  cached in `scripts/sync/.cache/` for 3 days, so a run that hits the limit can resume the
  next day for little extra cost.
- **Write guard:** the sync refuses to replace the catalogue with an empty one, or with one
  less than half the current size, unless you pass `--force`.
- **Overrides:** hand-written titles or synopses can be pinned per show in
  `scripts/sync/overrides.json`.

## Deployment

The site is a static Vite build and is configured for **Vercel** in `vercel.json`:

- **Routing:** page refreshes on any route, such as `/watch/…`, are served by the app.
- **Security headers:** a Content Security Policy that only allows YouTube's player and
  thumbnail servers, plus `Referrer-Policy: strict-origin-when-cross-origin`, which YouTube
  embeds require.
- **Caching:** built assets are cached long-term, and catalogue data is revalidated hourly.

To deploy your own copy, import the repository at [vercel.com/new](https://vercel.com/new) and
keep the detected settings. No environment variables are needed.

### Weekly refresh

`.github/workflows/sync-catalogue.yml` runs the sync every Monday at 07:30 UTC and runs the
tests. If the catalogue changed, it commits the new data, and Vercel redeploys. YouTube's API
policies require stored data to be refreshed regularly, and the weekly run also drops videos
that channels have removed.

To set it up, add the key under **Settings → Secrets and variables → Actions** as a repository
secret named `YOUTUBE_API_KEY`. Then trigger the first run from the **Actions** tab.

## Project structure

```
src/
  api/          catalogue API (remote JSON for the app, in-memory for tests) and React context
  components/   cards, search bar, filters, episode list, version picker, status messages
  hooks/        data loading (stale-response safe), debouncing, page titles
  lib/          search and ranking, URL state, YouTube URL helpers
  pages/        home, search, series, watch, privacy, not-found
  test/         render helpers, a fictional fixture catalogue, real-catalogue loader
scripts/sync/   catalogue pipeline: channels.json, YouTube + AniList clients,
                classification rules, writer and its tests
public/data/    generated catalogue (committed so the site builds without an API key)
```

## Testing

```bash
npm test
```

The tests cover:
- **Search:** ranking, filters, URL state, loading and stale responses, errors and retry,
  empty and no-results states.
- **Navigation:** routing, deep links, Back/Forward, keyboard access and page titles.
- **Watching:** the watch flow and version switching.
- **The sync pipeline:** playlist classification, season matching, pagination edge cases,
  the members-only filter and the write guard.
- **The generated catalogue:** checked for integrity.

UI tests run against a fictional fixture catalogue, so they don't change when real data does.
Separate tests check the real catalogue itself.

## Adding a channel

Add an entry to `scripts/sync/channels.json` with the channel's `UC…` ID, then run the sync.
**Only add channels operated by the rights holder or an official licensor.** Re-uploads,
fan channels and pirate sources don't belong here.

## Notes and limitations

- **Region:** what's playable depends on where you are. The published catalogue is filtered
  for India (`--region=IN`); visitors elsewhere may find some episodes unavailable.
- **Changing availability:** channels add and remove uploads, and some mark shows as
  "limited time". The weekly sync keeps up, but an episode can disappear in between.
- **Unmatched shows:** a few shows have no AniList match. They still play, but have no genres.
- **No affiliation:** this project isn't affiliated with or endorsed by YouTube, AniList,
  Crunchyroll or any of the channels listed. All videos, titles and artwork belong to their
  respective owners.
